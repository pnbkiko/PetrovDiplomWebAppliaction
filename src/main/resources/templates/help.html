Справка по системе ТО

Руководство пользователя системы управления техническим обслуживанием оборудования

Обзор системы

Система управления техническим обслуживанием (ТО) предназначена для автоматизации процессов планирования, учета и контроля технического обслуживания промышленного оборудования.

Основные возможности:

  • Учет оборудования — добавление станков с указанием типа, модели, модификации, производителя, года выпуска, серийного и инвентарного номеров
  • Виды ТО — настройка типов обслуживания с указанием периодичности в днях
  • График ТО — планирование дат проведения обслуживания для каждого станка
  • Акты ТО — документирование выполненных работ с указанием инженера
  • Календарь — визуальное отображение всех запланированных ТО на месяц
  • Поиск и фильтрация — быстрый поиск и фильтрация данных во всех таблицах
Рекомендуемый порядок работы:
  1. Добавьте оборудование в разделе "Оборудование"
  2. Создайте виды ТО в разделе "Виды ТО"
  3. Составьте график ТО в разделе "График ТО"
  4. После выполнения ТО создайте акт в разделе "Акты ТО"
  5. Контролируйте сроки через "Календарь ТО"

Управление оборудованием

Раздел предназначен для ведения реестра обслуживаемого оборудования. Каждый станок имеет подробную карточку с техническими характеристиками.

Поля карточки оборудования:

Поле Обязательность Описание
Тип оборудования Обязательное Выбирается из справочника типов (Токарный станок, Фрезерный станок, Пресс и т.д.)
Модель Обязательное Модель станка (например: CTX-500, FV-580, HP-300)
Модификация Необязательное Исполнение, поколение или серия (например: 1-е поколение, Усиленная, Серия С). Позволяет различать станки одной модели
Производитель Обязательное Завод-изготовитель (например: DMG MORI, Haas, СтанкоМаш)
Год выпуска Необязательное Год производства станка. Отображается цветом: зеленый — новые (2020+), желтый — средние (2010-2019), серый — старые (до 2010)
Серийный номер Необязательное Заводской серийный номер станка
Инвентарный номер Обязательное Уникальный инвентарный номер в вашей организации
Дата ввода Обязательное Дата ввода станка в эксплуатацию

Поиск и фильтрация:

  • Поиск — введите текст в поле поиска для фильтрации по всем полям (тип, модель, модификация, производитель, серийный и инвентарный номера)
  • Фильтр по типу — выберите тип оборудования из выпадающего списка
  • Фильтр по году — фильтрация новых (2020+), средних (2010-2019) или старых (до 2010) станков
  • Сброс — кнопка "Сбросить" очищает все фильтры
Важно: Инвентарный номер должен быть уникальным. Система не позволит создать два станка с одинаковым инвентарным номером.

Виды технического обслуживания

Справочник видов технического обслуживания с указанием периодичности выполнения.

Поля справочника:

Поле Описание
Название Наименование вида ТО (например: Ежемесячное ТО, Замена масла, Калибровка)
Интервал (дней) Периодичность выполнения в днях (от 1 до 365)

Категории интервалов:

  • ● Ежедневные — 1 день
  • ● Еженедельные — 2-7 дней
  • ● Ежемесячные — 8-30 дней
  • ● Квартальные — 31-90 дней
  • ● Годовые — более 90 дней
Совет: При создании акта ТО система автоматически обновляет график: дата последнего ТО становится текущей, а дата следующего ТО рассчитывается как текущая дата + интервал.

График технического обслуживания

График ТО показывает запланированные даты обслуживания для каждой пары "станок — вид ТО".

Как добавить запись в график:

  1. Выберите оборудование из выпадающего списка
  2. Выберите вид ТО
  3. Укажите дату последнего выполненного ТО (если было)
  4. Укажите планируемую дату следующего ТО
  5. Нажмите "Сохранить"

Статусы записей:

  • ⚠ Просрочено — дата следующего ТО уже прошла
  • 📅 Сегодня — ТО запланировано на сегодня
  • ✓ По графику — ТО запланировано на будущую дату
Внимание: При создании акта ТО график обновляется автоматически — дата последнего ТО становится датой из акта, а следующая дата рассчитывается с учетом интервала.

Акты технического обслуживания

Акты ТО фиксируют факт выполнения технического обслуживания с указанием исполнителя и результатов.

Поля акта ТО:

Поле Описание
Оборудование Станок, на котором проводилось ТО
Вид ТО Тип выполненного обслуживания
Дата выполнения Дата проведения работ
Инженер ФИО специалиста, выполнившего ТО
Примечания Дополнительная информация о выполненной работе
Акт подписан Отметка о подписании акта (чекбокс с иконкой подписи)
Автоматическое обновление графика: При создании акта ТО система автоматически обновляет график — устанавливает дату последнего ТО и рассчитывает следующую дату.

Календарь ТО

Календарь отображает все запланированные ТО на выбранный месяц в наглядном виде.

Навигация:

  • Стрелки — переключение между месяцами
  • Кнопка "Сегодня" — возврат к текущему месяцу

Цветовые обозначения:

  • Белый — обычный день
  • Желтый фон — день с запланированными ТО
  • Синяя рамка — сегодняшний день
  • Серый — дни другого месяца

Просроченные ТО:

Под календарем отображается таблица просроченных ТО с указанием количества дней просрочки.

Часто задаваемые вопросы

Как добавить новое оборудование?

Перейдите в раздел "Оборудование", заполните форму в верхней части страницы: выберите тип, укажите модель, производителя, при необходимости — модификацию и год выпуска, введите серийный и инвентарный номера, укажите дату ввода в эксплуатацию. Нажмите "Сохранить".

Чем отличается модель от модификации?

Модель — это базовая марка станка (например, CTX-500). Модификация — это конкретное исполнение или поколение этой модели (например, "1-е поколение" 2003 года выпуска и "3-е поколение" 2024 года — это разные модификации одной модели CTX-500).

Как работает автоматическое обновление графика ТО?

При создании акта ТО система автоматически находит запись в графике для этой пары "станок — вид ТО" и обновляет её: устанавливает дату последнего ТО равной дате из акта, а дату следующего ТО рассчитывает как дата акта + интервал из справочника видов ТО.

Как найти нужный станок в таблице?

Используйте поле поиска над таблицей. Поиск работает по всем полям: типу, модели, модификации, производителю, серийному и инвентарному номерам. Также можно использовать фильтры по типу оборудования и году выпуска. Горячие клавиши: Ctrl+F — фокус на поиск, Esc — сброс фильтров.

Что означают цвета года выпуска?

Цвет бейджа года выпуска показывает возраст станка:

  • Зеленый — новые станки (2020 год и новее)
  • Желтый — средний возраст (2010-2019 годы)
  • Серый — старые станки (до 2010 года)
